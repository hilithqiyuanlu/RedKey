# AlphaKey Windows 使用说明

适用：Windows 10 或 Windows 11 的 64 位电脑。

1. 双击 `AlphaKey_0.1.0_x64-setup.exe` 安装，再从开始菜单打开 AlphaKey。
2. 不需要安装 Python、Node.js 或任何开发工具。
3. 第一次使用图片识别或录音转写时，应用会提示下载本地 AI 组件。保持联网并等待下载完成即可；之后这些功能可以离线使用。
4. 图片文字识别：进入一个任务后，直接按 `Ctrl+V` 粘贴截图，或点击图片卡添加图片。识别会在后台进行，图片会先显示出来。
5. 录音：在任务里点击录音按钮。首次转写会提示下载语音组件，下载完成后再进行转写。
6. 关闭主窗口只是隐藏应用；需要完全退出时，在右下角系统托盘中选择“退出 AlphaKey”。

常见情况：

- Windows 弹出 SmartScreen 提示：这是因为当前安装包尚未做正式代码签名。请只安装从可信发送者处收到的安装包，确认来源无误后可在“更多信息”中选择运行。
- 本地 AI 组件下载失败：打开“设置”，在“本地运行环境”或“本地模型”中点击重试。
- 本地数据保存在这台电脑上，不需要登录账号。DeepSeek 总结功能需要你自己在设置中填写 API Key。
