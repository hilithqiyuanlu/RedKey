# AlphaKey Windows 快速上手

AlphaKey 把正在推进的任务放在数字键上。资料、截图、录音和整理结果都留在同一张任务卡里，方便随时回看。

```text
创建任务 -> 绑定数字键 -> 随时切换 -> 粘贴资料 / 开始录音 -> 查看整理结果
```

## 先开始

1. 双击 `AlphaKey_0.1.0_x64-setup.exe` 完成安装。
2. 从开始菜单打开 AlphaKey，创建第一个任务，并为它选择一个数字槽位。
3. 日常工作时，直接用快捷键切换到对应任务，再把文字、截图或录音放进去。

第一次使用图片识别或录音转写时，AlphaKey 会提示下载本地组件。保持联网完成下载即可；下载完成后，识别和转写可离线使用。

## 常用快捷键

默认快捷键前缀为 `Ctrl + Alt`。可以在“设置 -> 通用 -> 快捷键前缀”中换成自己习惯的组合键。

| 操作 | 默认按键 | 效果 |
| --- | --- | --- |
| 打开任务 1-9 | `Ctrl + Alt + 1` 到 `9` | 切换到对应数字槽位的任务 |
| 打开任务 0 | `Ctrl + Alt + 0` | 切换到第 10 个数字槽位的任务 |
| 开始 / 停止录音 | `Ctrl + Alt + T` | 在当前任务中切换录音状态 |
| 粘贴资料 | `Ctrl + V` | 在任务页面空白处粘贴图片或文字 |

提示：当光标正在输入框或编辑器内时，`Ctrl + V` 仍是普通粘贴，不会新建卡片。

## 卡片怎么用

| 卡片 | 快捷操作 | 适合放什么 |
| --- | --- | --- |
| 文本卡 | 双击内容直接编辑 | 临时备注、需求、会议要点 |
| 图片卡 | 粘贴截图后自动识别；双击识别文字可编辑 | 截图、原型、聊天记录 |
| 录音卡 | 用快捷键或麦克风按钮录音；展开后查看转写和总结 | 会议、电话、口述需求 |

录音结束后会依次完成转写和 AI 梳理。展开录音卡后，音频和原始转写只读；双击“对接结论”或“待办行动”可直接修改整理内容。负责人和截止时间会继续显示在待办旁边。

卡片右上角的铅笔用于编辑，箭头用于展开或收起，垃圾桶用于删除。拖动任务槽位可以调整任务位置。

## 一次典型使用

1. 用 `Ctrl + Alt + 数字键` 打开正在沟通的任务。
2. 遇到资料就按 `Ctrl + V`：截图会成为图片卡，文字会成为文本卡。
3. 开会或通话时按 `Ctrl + Alt + T` 开始录音，结束时再按一次。
4. 等待录音卡显示“已完成”，展开查看对接结论和待办行动。
5. 需要补充时，双击对应摘要区域直接改；修改会自动保存。

## 需要留意

- AI 总结需要在“设置”中填写自己的 DeepSeek API Key；不填写也不影响任务、图片、录音和本地转写。
- 关闭主窗口只是隐藏 AlphaKey。要完全退出，请在右下角系统托盘选择“退出 AlphaKey”。
- Windows 出现 SmartScreen 提示时，请先确认安装包来源可信；当前安装包尚未进行正式代码签名。
- 本地组件下载失败时，进入“设置”里的“本地运行环境”或“本地模型”点击重试。
